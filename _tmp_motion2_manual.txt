1 Connection

1.1 Serial Port

To connect to a motion 2 card use the following serial port settings:
     · Baud Rate: 38400
     · Parity: None
     · Stop Bits One
     · New Line: Carriage return character (ASCII 0xD)

2.1.2 DESC
Stores a string of up to 40 ASCII characters on the card that is typically used to help distinguish devices.
The description string is also used by LinLab 2 to name the tabs related to that device.

Get Description

          Description: Gets the description string to be stored on the unit.
               Syntax: DESC

           Parameters: None
              Returns: The description string to be stored on the unit.
               Sample: DESC LEFT PATCHSTAR

Set Description

       Description: Sets the description string to be stored on the unit.
           Syntax: DESC

       Parameters: <description> string to be set as the description string, maximum of 40 characters
          Returns: Acknowledgement character (A)
           Sample: DESC RIGHT PATCHSTAR A

2.1.3 ID
A card ID number that is used as an address when devices are communicating to each other and to control
devices. The ID can be set either via a rotary switch on the rack or by storing a value in the card. Devices
should not have the same ID as any other within the system and numbers from 1 - 20 should be used
except within specialised systems.

Get Current ID

          Description: Gets the ID currently being used by the card.
               Syntax: ID

           Parameters: None
              Returns: The ID currently being used by the card.
               Sample: ID 1

Reread ID

       Description:  Sets the card into auto read ID mode and reads the state of the rotary switch on
                     the rack and then returns the new value. Auto read ID mode means that the card
                     will read the rotary switch at start up and use that as the ID, if the rotary switch is
                     changed after start up the ID will not change unless this command is used.

           Syntax: ID

       Parameters: ?

           Returns: The ID currently being used by the card.

           Sample: ID ? 1

Get Stored ID

          Description: Gets the ID stored in the card or 0 if the card is in auto ID mode.
               Syntax: ID

           Parameters: A
              Returns: The ID stored in the card or 0 if the card is in auto ID mode.
               Sample: ID A 0

uses this value to setup some of the settings and LinLab 2 uses this value to provide the correct user

2.6 Follow

Allows manipulators with pipettes or electrodes attached to them to follow a stage so that the pipettes or
electrodes remain in view.

2.6.0.1 Calibration
     · Align pipettes or electrodes on following devices to a cross hair on the view of the lead device.

     · Send FCAL Step 1 to all devices (following and lead devices).

     · Move the lead device by at least 2mm in the X axis (the greater the distance moved the more
       accurate the follow is likely to be) and then realign all of the pipettes and electrodes to the cross
       hair.

     · Send FCAL Step 2 to the following devices with the FQ follow position of the lead as the argu-
       ments.

     · Move the lead device by at least 2mm in the Y axis (the greater the distance moved the more
       accurate the follow is likely to be) and then realign all of the pipettes and electrodes to the cross
       hair.

     · Send FCAL Step 3 to the following devices with the FQ follow position of the lead as the argu-
       ments.

     · Move the lead device in the Z axis so the pipettes and electrodes are out of focus and then refocus
       the pipettes and electrodes .

     · Send FCAL Step 4 to the following devices with the FQ follow position of the lead as the argu-
       ments.

     · Send FCAL Step 5 to the following devices.
